# 来源与交付完整性审计

ReviewWrite 提供只读的来源与交付完整性审计，不提供水印移除、来源伪装、检测器规避或作者身份重写。

## 能确认什么

审计可以报告输入中实际发现的可观察线索，例如 C2PA/JUMBF 容器标记、明确的 SynthID 文档或元数据引用，以及可能影响交付完整性的 Unicode 格式控制字符。发现线索不等于完成来源归属认证；“未发现”也不等于“确定不存在”。

文本水印、模型来源分类器和平台内部信号不能被 ReviewWrite 当作作者证明。文本审写仍以事实、引用、限定条件和作者披露为准。

## 使用方式

```bash
python3 scripts/reviewwrite_provenance.py path/to/file --format json
python3 scripts/reviewwrite_provenance.py --text '待审计文本' --format json
```

默认只读标准输入、文本文件、DOCX 和二进制文件中的可观察标记。脚本不覆盖原文件，不删除元数据，不清除不可见字符，也不上传内容。

## 交付原则

- 保留输入中的来源标记和 Content Credentials；
- 对格式控制字符先定位、再由作者或专业人员确认用途；
- 将“已检测到”“未检测到”和“无法判断”分开报告；
- 需要发布时遵守平台、机构和任务本身的 AI 使用披露要求；
- 不把自然化改写宣传成“证明由人完成”，也不把来源信号缺失宣传成“已经清除”。
